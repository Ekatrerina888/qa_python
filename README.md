## Покрытые сценарии тестирования

Тестами проверены следующие функциональные возможности класса `BooksCollector`:

* **Инициализация:** корректное создание пустого экземпляра класса.
* **Добавление книг:**
    * добавление книг с корректными названиями;
    * обработка пустых названий;
    * проверка ограничения длины названия (> 40 символов);
    * добавление нескольких книг.
* **Управление жанрами:**
    * установка допустимых жанров;
    * отказ от установки недопустимых жанров;
    * получение жанра по названию книги.
* **Фильтрация и поиск:**
    * поиск книг по конкретному жанру;
    * фильтрация книг для детей (исключая жанры из `genre_age_rating`).
* **Работа со списком избранного:**
    * добавление книги в избранное;
    * удаление книги из избранного;
    * попытка добавить несуществующую книгу в избранное.
* **Получение данных:**
    * получение полного словаря книг с жанрами;
    * получение списка избранных книг.
